📚 TripTrek India - Frontend Documentation
Project Overview
TripTrek India is a React-based travel package booking platform that allows users to browse destinations, view travel packages, and make secure payments. The application features a modern UI with Tailwind CSS, responsive design, and seamless navigation.

1. src/main.jsx - Entry Point
javascript

Purpose: Application entry point that mounts the React app to the DOM.

2. src/App.jsx - Routing Configuration
Route Path	Component	Description
/	HomePage	Home page with all sections
/destinations	HomePage	Same as home (scrolls to destinations)
/destination/:id	UnifiedDetail	Shows destination details (Kakani Lake, Chakrata, Kedarnath, Tungnath)
/package/:id	UnifiedDetail	Shows package details (Char Dham)
/package/:id/payment	Payment	Payment page for packages
/blogs	BlogsPage	All blog posts listing
/blogs/:slug	BlogPostPage	Individual blog post
/profile	ProfilePage	User profile page
/auth/callback	AuthCallback	OAuth callback handler
Layout Wrapper: All routes (except /auth/callback) use the Layout component which includes Header and Footer.

🔄 Data Flow Diagram
text
User clicks on Destination/Package Card
    ↓
Navigates to /destination/:id or /package/:id
    ↓
UnifiedDetail.jsx loads
    ↓
Detects route type (destination or package)
    ↓
Fetches data from destinations.js or packages.js
    ↓
Displays details with booking sidebar
    ↓
User selects date, travelers, applies coupon
    ↓
Clicks "Proceed to Payment"
    ↓
Navigates to /package/:id/payment with booking data in state
    ↓
Payment.jsx displays order summary and payment form
    ↓
User submits payment
    ↓
Success page (booking confirmed)
🎨 Styling Guidelines
Framework: Tailwind CSS

Color Scheme:

Primary: Blue to Purple gradients (from-blue-600 to-purple-600)

Indian Theme: Saffron (saffron-500), Green (green-500), White

Background: Gray-50 to white gradient

Responsive Breakpoints: sm (640px), md (768px), lg (1024px), xl (1280px)

Icons: lucide-react library
